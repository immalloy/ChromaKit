## Quick Start

1. Put your WAV samples in one folder.
2. Open ChromaKit.
3. Choose or drag in that folder.
4. Click **Generate Chromatic**.

Need the more understandable tutorial? Read the [beginner tutorial](docs/tutorial.md).
